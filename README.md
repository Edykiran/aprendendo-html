# 🚀 Meus Estudos de HTML

Bem-vindo(a) ao meu repositório de aprendizado! Este espaço foi criado para registrar minha evolução, anotar conceitos importantes e armazenar os exercícios práticos desenvolvidos enquanto aprendo as bases do **HTML**.

---

## 📌 Sobre o Repositório

O objetivo deste projeto é documentar toda a minha jornada de estudos em desenvolvimento web, começando do zero com HTML. Aqui você encontrará:

- **Conceitos básicos e estrutura inicial:** Tags, atributos e elementos fundamentais.
- **Formatação de texto:** Títulos (`<h1>` a `<h6>`), parágrafos (`<p>`), destaques e listas.
- **Mídia:** Inclusão e otimização de imagens (`<img>`), áudio e vídeos.
- **Links e Navegação:** Criação de links internos, externos e âncoras (`<a>`).
- **Tabelas e Formulários:** Estruturação de dados e criação de campos de entrada de dados (`<input>`, `<form>`).
- **HTML Semântico:** Uso correto de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` e `<footer>`.
